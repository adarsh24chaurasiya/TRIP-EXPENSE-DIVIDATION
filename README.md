# 🎟️ TripSplit

A clean and elegant group expense splitter to split trip costs fairly — add members, log expenses, and get an instant settlement plan showing who owes whom.

🔗 **Live Demo:** [tripsplito.netlify.app](https://tripsplito.netlify.app/)

## ✨ Features

- 👥 **Add Trip Members** — with auto-generated, color-coded avatars
- 💳 **Log Expenses** — who paid, what for, how much, and when
- ⚖️ **Auto Settlement Calculation** — minimal payments to settle everyone up
- 🤝 **Mark Payments as Paid** — track pending vs. completed settlements
- 📊 **Member Balances** — total paid, fair share, and net status at a glance
- 🔍 **Searchable Expense Ledger** — with edit and delete support
- ✏️ **Rename Trip & Reset Data** anytime
- 💾 **Auto-Saved** — data stays in your browser via localStorage
- 📱 **Fully Responsive**

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository

   ```bash
   git clone https://github.com/<your-username>/tripsplit.git
   ```

2. Open `index.html` in your browser

3. Start splitting expenses!
